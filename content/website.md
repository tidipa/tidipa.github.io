title: About this Website
---

This website is currently hosted on [Github Pages](https://pages.github.com). It is a Github Repository called [tidipa.github.io](https://github.com/tidipa/tidipa.github.io).

The website pages are authored in [Github Flavored Markdown](https://github.github.com/gfm/) using a combination of [Obsidian](https://obsidian.md) and [Visual Studio Code](https://code.visualstudio.com). A static site generator called [Quartz](https://quartz.jzhao.xyz/) is used to convert the Markdown files into a static web site.

The font family used for this website is [Noto](https://fonts.google.com/noto).

The images on this website are created using a generative model ([Imagen 4](https://deepmind.google/models/imagen/)). These images are generated using very specific prompts to convey a consistent artistic style and reflecting elements of the translated text.

Citations and references on this website are in [APA Style](https://apastyle.apa.org).
