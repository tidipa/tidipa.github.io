This website is currently hosted on [GitHub Pages](https://pages.github.com). It is a GitHub Repository called [tidipa.github.io](https://github.com/tidipa/tidipa.github.io).

The website pages are authored in [GitHub Flavored Markdown](https://github.github.com/gfm/) using a combination of [Obsidian](https://obsidian.md) and [Visual Studio Code](https://code.visualstudio.com). The [Astro](https://astro.build) static site generator, with the [Starlight](https://starlight.astro.build) documentation theme, is used to convert the Markdown files into a static website.

The font family used for this website is [Noto](https://fonts.google.com/noto). Pāḷi text in the website is represented using the International Alphabet of Sanskrit Transliteration (IAST) and the text should be pronounced in accordance with the International Phonetic Alphabet for Pāḷi (IPA Pāḷi). Pāḷi words are usually highlighted using a monospaced font (as an example `buddho` meaning "the one who understood" but also "The Buddha" expressed in nominative form). On rare occasions, Sanskrit words are used; these are highlighted with a '[S]' prefix (for example [S]`Ṛg Veda`).

The images on this website are created using a generative model ([Imagen 4](https://deepmind.google/models/imagen/)). These images are generated using very specific prompts to convey a consistent artistic style and reflect elements of the translated text.

Citations and references on this website are in [APA Style](https://apastyle.apa.org).
